# 实验07：用深度学习找圈子——嵌入聚类（说明书 §6.5）

**这个实验回答的问题**：不用手工设计指标，让神经网络自己"看懂"网络结构，能分出社区吗？节点属性（研究兴趣）能帮上忙吗？

**用什么数据**：`研究者合作属性网络.json`（20 位研究者、两个主题社群，每人带 topic 属性 + 4 维兴趣特征）。

**怎么进入**：自由实验室 → 第一步「导入文件」选本文件夹的 `研究者合作属性网络.json`（自带 topic 属性）→「校验图数据」。（此数据无对应案例页，用导入路线。）

**操作步骤（约 10 分钟）**
1. 选 **「AE 属性自编码嵌入聚类」** → 参数 `clusters=4`、`epochs=100` → 运行；
2. 选 **「CNN 卷积嵌入聚类」** → 相同参数 → 运行；
3. 对比两者聚类结果与 topic 属性的一致程度（节点 P01–P10 是主题 A，P11–P20 是主题 B）；
4. 选 **「GCN 嵌入适配器」** 或 **「GAT 嵌入适配器」**：当前服务器未启用 PyTorch 运行时，平台会明确提示 **"能力不可用"**——**这不是故障**。课堂话术："平台宁可报'我不会'也不编造结果，这是科学计算和算命的区别。"（需要解锁 GCN/GAT 时联系管理员部署 ML 镜像。）

**带学生看什么**：聚类表 + 嵌入坐标图；对比传统 Louvain（实验05）——深度学习方法联合了**节点属性**，不只是连线。

**课堂话术**："前面所有算法都是人定规则；这三个是让机器自己从数据里学表示——这是图深度学习的入门。"
