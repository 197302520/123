# 实验03：网络的基本体检 + 最短路 + 三种经典网络（说明书 §4）

**这个实验回答的问题**：怎么用几个数字概括一个网络？任意两人怎么走最短路？真实社交网络和随机网络差在哪？

**用什么数据**
- `空手道俱乐部网络.txt`（主数据）
- ER / WS / BA 三个生成器算法**不需要任何数据**，平台直接生成！

**怎么进入**：路线A 免导入：案例库 →「Zachary 空手道俱乐部」→ 在「运行分析」标签点「运行分析」就地出结果；或路线B 导入本文件夹 txt。

**操作步骤（约 15 分钟）**
1. 选 **「拓扑摘要」** → 运行 → 抄下黑板上两个数：**平均聚类系数 C** 和 **平均最短路径 L**（§4.1、§4.3）；
2. 选 **「Floyd 全源最短路」** → 运行 → 看最短距离矩阵 + **任意两点的完整路径节点序列**（现场挑两个节点把路径念出来）+ 全网平均最短路径（§4.2）；
3. 选 **「聚类系数」** → 运行 → 排序看"朋友圈最抱团"的人（§4.3）；
4. **不用数据**，直接选 **「ER 随机图」**（n=30, p=0.1）运行 → 看聚类系数极低、度分布像泊松；
5. 选 **「WS 小世界图」**（n=30, k=4, p=0.1）→ 高聚类 + 短路径；
6. 选 **「BA 无标度图」**（n=30, m=2）→ 度分布幂律、出现超高度枢纽（§4.4 判别标准）。

**带学生看什么**：把 1 的 C、L 与 4~6 的三种模型并排对比——空手道网络 C 高 L 短，ER 模型解释不了，WS/BA 各解释一半。

**课堂话术**："真实社交网络既不是完全随机撒边，也不是完全规则——WS 给了它'朋友圈抱团'，BA 给了它'人缘王'。"

**注意**：Floyd 是 O(n³)，平台限制 500 节点以内——顺势讲算法复杂度。
