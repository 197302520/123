# 实验05：把网络分成圈子——非重叠社区发现（说明书 §6.1–6.3）

**这个实验回答的问题**：网络里自然存在哪些"小团体"？哪个算法分得最好？

**用什么数据**：`空手道俱乐部网络.txt`（真实历史：俱乐部后来确实分裂成两派，是社区发现的"标准答案"数据）。

**怎么进入**：路线A 免导入：案例库 →「Zachary 空手道俱乐部」→ 在「运行分析」标签点「运行分析」就地出结果；或路线B 导入本文件夹 txt。

**操作步骤（按"从笨到聪明"的方法演进史讲，约 25 分钟）**
1. 先口头讲评判标准：**模块度 Q**（§6.2，Q 越大划分越清晰）与强/弱社区判定（§6.1）——后面每跑一个算法都看它的 Q；
2. 选 **「KL 二分算法」**（目标社区数=2）→ 只能分两半："入门算法的局限"；
3. 选 **「凝聚层次聚类」** → 看**聚类树**；再选 **「分裂层次聚类」** 对照（自下而上 vs 自上而下，§6.3.2）；
4. 选 **「Girvan–Newman」** → 经典必讲：边介数→删边→迭代（§6.3.3）；
5. 选 **「Fast Newman」** → 以 Q 最大化为目标，比 GN 更科学（§6.3.4）；
6. 选 **「Louvain」**（resolution=1.0）→ 工业界标配，速度快精度高（§6.3.5）；
7. 选 **「Leiden」** → 若出现"回退为 Louvain"的提示属正常（服务器未装 igraph 时平台如实报告），正好讲"平台不伪造结果"（§6.3.6）；
8. 选 **「LPA 标签传播」** → **换 3 个不同随机种子各跑一次**，结果可能不同 → 讲"零参数但随机"的取舍（§6.3.7）；
9. **收尾必做**：选 **「多算法模块度对比」** → 一张表排出所有算法的 Q 值 + 强/弱社区判定，直接回答"谁分得最好"（§6.7）。

**加分演示（多尺度）**：Louvain 把 `resolution` 改 0.5 / 1.0 / 2.0 各跑一次 → 社区数从少变多 → 讲分辨率参数（§6.2 带分辨率模块度）。

**课堂话术**："节点颜色就是算法分出的圈子——回到网络叠加层，肉眼对比哪个算法分的圈子和俱乐部真实分裂最像。"
