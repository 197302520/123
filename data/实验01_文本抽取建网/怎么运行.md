# 实验01：从一段中文新闻自动画出关系网络（说明书 §2）

**这个实验回答的问题**：给一段自然语言文本，电脑怎么自动找出"谁和谁有关系"并画成网络？

**用什么数据**：本文件夹的 `企业关系新闻文本.txt`（12 句新能源汽车产业链新闻，故意让"华为"和"华为公司"并存，用来演示同指实体合并）。

**怎么进入**
- 打开平台 → 顶部导航「自由实验室」（/lab）。
- 本实验**不需要导入任何文件**：算法吃的是"文字"不是"图"，文本是粘贴进参数里的。

**操作步骤**
1. 第二步「选择算法」→ 下拉选模块一的 **「中文实体关系建网」**。
2. 在下方参数区找到 **「待抽取中文文本」**，把 `企业关系新闻文本.txt` 的全部内容粘贴进去。
3. 其余参数保持默认（`method=rule`，`embedding=cosine`，`merge_threshold=0.6`）。
4. 点第三步 **「运行真实算法」**。

**带学生看什么**
1. **实体表**（抽出了哪些公司）和**关系表**（谁和谁有什么关系、出现几次）；
2. **同指实体合并表**：应能看到"华为 / 华为公司"被合并为一个节点——这就是 `merge_threshold` 的作用；
3. 把 `embedding` 改成 `normalized`（频次归一化权重）再跑一次，对比同一条边权重的变化 → 讲 §2.2 两种权重语义（余弦相似度 vs 交互频次归一化）；
4. 把 `merge_threshold` 改成 0（关闭合并）再跑 → 让学生数节点数变多没有。

**课堂话术**："文本清洗 → 实体识别 → 关系抽取 → 频次统计，四步全自动；但规则法会漏掉隐含关系——注意看警告栏，平台抽不出就说抽不出，绝不编造。"
