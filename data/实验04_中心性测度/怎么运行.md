# 实验04：谁是这个网络里最重要的人？——七种中心性（说明书 §5）

**这个实验回答的问题**：什么叫"重要"？朋友最多？消息最快？还是桥梁人物？

**用什么数据**
- `空手道俱乐部网络.txt` → 六个无向指标（度/接近/中介/特征向量/中心势）
- `国际贸易流向.json`（14 经济体出口流向，自带有向）→ PageRank、HITS
- `世界杯球员俱乐部.csv`（切有向）→ 出度/入度

**怎么进入**：路线A 免导入：案例库 →「Zachary 空手道俱乐部」→ 在「运行分析」标签点「运行分析」就地出结果；或路线B 导入本文件夹 txt。

**操作步骤（建议 20 分钟连做）**
1. 依次选 **「度中心性」→「接近中心性」→「中介中心性」→「特征向量中心性」** 各运行一次，每次看两个地方：结果表按值排序的第一名 + 网络叠加层（节点大小随指标变化）；
2. 重点讲 **中介中心性**：通常冒出一个度不高但中介性极高的"桥梁人"（§5.3）；
3. 选 **「度中心势」** 运行 → 全网层面"影响力集中度"（§5.7，只支持无向图）；
4. 导入 `国际贸易流向.json`（自带 directed:true）→ 选 **「PageRank」**（α=0.85，可改 0.5 对比排名变动）→ 再选 **「HITS」** → Hub 与 Authority 两列分开看（§5.5、§5.6）；
5. 导入 `世界杯球员俱乐部.csv`、切有向 → **「度中心性」** → 表格分**出度**（球员主动关联）/ **入度**（俱乐部被关联）两列。

**带学生看什么**：同一网络下四种中心性的第一名往往**不是同一个人**——引出"中心性是多维概念，选指标就是选理论视角"。

**课堂话术**："度数高是'人缘好'；中介高是'得罪不起'；特征向量高是'认识的都是大佬'——三个词概括三种成功学。"
